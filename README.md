# Oyzu examples

Self-contained native projects and canonical recipes for standalone Oyzu use.
Implementation is in progress for oyzuai/oyzu#611. Nothing here requires a
platform account. Planned capabilities must not be presented as working recipes.

The maintainer selected Apache-2.0 for this collection on 2026-10-17.
See [LICENSE](LICENSE) and [contribution guidance](CONTRIBUTING.md).
Upstream tools retain their own terms. Samples added here are original work,
with no imported upstream project source. Oyzu's own source visibility and
distribution audit remain separate.

The collection will provide guided learning paths and a searchable catalog.
Recipes own their instructions; the Oyzu documentation site imports selected
content at an exact reviewed commit. Implementation and verification are pending.
